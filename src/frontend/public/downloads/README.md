# Downloads Directory

This directory serves static assets for download, specifically the Android APK file for the Calorieshivam mobile app.

## Purpose

- **Static Asset Serving:** Files in this directory are served as static assets at `/downloads/*` when the frontend is deployed.
- **APK Distribution:** The Android wrapper packaging script exports the release APK to `Calorieshivam.apk` in this directory, making it available at the stable URL path `/downloads/Calorieshivam.apk`.
- **Version Control:** The `.gitkeep` file ensures this directory exists in version control even when empty.

## Expected Files

- **`.gitkeep`** - Placeholder file to preserve the directory in Git (must not be removed)
- **`Calorieshivam.apk`** - Android release APK (generated by `frontend/android-wrapper/scripts/package-release-apk.sh`)

## Important Notes

- **Do not remove `.gitkeep`** - This file ensures the downloads directory structure is preserved in version control
- **APK is generated, not committed** - The `Calorieshivam.apk` file is generated by the Android packaging script and should not be committed to version control (add to `.gitignore` if needed)
- **Web distribution** - When the APK is present, it's available for download at `/downloads/Calorieshivam.apk` from the deployed web app

## Packaging Flow

1. Configure production URL in `frontend/android-wrapper/gradle.properties`:
   ```properties
   nutriscan.baseUrl=https://<YOUR_CANISTER_ID>.ic0.app
   ```
2. Run the packaging script:
   ```bash
   bash frontend/android-wrapper/scripts/package-release-apk.sh
   ```
3. Script validates configuration, builds the Android APK, and copies it to `frontend/public/downloads/Calorieshivam.apk`
4. APK becomes available for download at `/downloads/Calorieshivam.apk` when the frontend is deployed

## Output Location

- **Local path:** `frontend/public/downloads/Calorieshivam.apk`
- **Deployed URL:** `/downloads/Calorieshivam.apk` (static asset served by the web app)

For detailed instructions, see `frontend/android-wrapper/README.md`.
